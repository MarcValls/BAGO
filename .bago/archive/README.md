# BAGO — Archivo histórico

verdad operativa; los contratos actuales viven en `../../docs/` y el arranque en
`../BOOTSTRAP.md`.

- `CLI_*` — documentación histórica de CLI v3.
- `TABLET_*` y `README_TABLET_START_HERE.md` — despliegue tablet.

- `DEMO_*`, `*VERIFICATION*`, `GUIDE_HOW_TO_USE.md` — demos, guías y verificaciones antiguas.
- `INDEX_FACTORY_DEMO.md` — índice histórico anterior de factory/demo.
