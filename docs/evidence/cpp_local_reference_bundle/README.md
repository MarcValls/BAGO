# Archived Experimental Evidence

This bundle is an archived `cpp-local` reference captured before the current v4.1.5 MVP boundary.

It is not current release evidence and must not be used to claim that the C++ runtime is part of the stable product path.

Current release evidence must come from:

```powershell
python test_security_release.py
python test_e2e.py
python bago_core\cli.py validate
python bago_core\cli.py evidence --test
```

The C++ runtime remains experimental according to `docs/MVP.md` and `docs/MODULES.md`.
