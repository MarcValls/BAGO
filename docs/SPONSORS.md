# BAGO para sponsors

BAGO busca financiar un runtime local-first para desarrollo asistido por IA:

- control de credenciales por dispositivo;
- modelos locales y cloud bajo una matriz de routing auditable;
- memoria `bago-knowledge` separada del framework;
- portabilidad mediante dispositivo BAGO;
- herramientas de validacion, estado y auditoria.

## Que se patrocina

- estabilidad del instalador en Windows, macOS y Linux;
- documentacion y onboarding;
- seguridad de credenciales;
- conectores de modelos y proveedores;
- flujo de comunidad para compartir conocimiento curado.
