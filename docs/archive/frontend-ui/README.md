# Informes históricos del frontend

Los informes versionados de UI que antes estaban en `frontend/` describen
propuestas, validaciones y builds fechados de BAGO UI v2. No definen el
producto frontend actual ni deben tratarse como su contrato. Se conservan con
sus nombres y contenido originales para mantener la referencia histórica.

El contrato vigente está en [`frontend/PRODUCT.md`](../../../frontend/PRODUCT.md)
y [`frontend/CONTEXT_PRODUCT_CONTRACT.md`](../../../frontend/CONTEXT_PRODUCT_CONTRACT.md).
