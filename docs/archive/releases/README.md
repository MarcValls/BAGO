# Archivo de releases históricas

Estos documentos preservan el contenido publicado o preparado para versiones
anteriores. Sus nombres mantienen la versión a la que pertenecen; no son
instrucciones vigentes ni sustituyen [`release_version.txt`](../../../release_version.txt).

| Versión | Documento | Contenido |
|---|---|---|
| 4.8.2 | [Manifest](RELEASE_4.8.2_MANIFEST.md) | Correspondencia histórica entre tag y artefactos. |
| 4.8.2 | [Entrega del instalador](INSTALLER-DELIVERY_4.8.2.md) | Instrucciones del instalador de esa versión. |
| 4.8.3 | [Notas](RELEASE_NOTES_4.8.3.md) | Capacidades y validación de la release. |
| 4.8.4 | [Notas](RELEASE_NOTES_4.8.4.md) | Notas de release preservadas. |
| 4.8.4 | [Resumen de publicación](RELEASE_PUBLICATION_SUMMARY_4.8.4.md) | Registro histórico de publicación. |
| 4.8.7 | [Notas](RELEASE_NOTES_4.8.7.md) | Capacidades, artefactos y validación de la release. |
| 4.9.0 | [Release readiness](RELEASE-READY_4.9.0.md) | Checklist histórica; no describe el estado actual. |
| 4.10.0 | [Notas](RELEASE_NOTES_4.10.0.md) | Notas de una release anterior; no es autoridad de versión actual. |
| 4.9.0 | [Índice local pre-remediación](LOCAL_RELEASE_INDEX_PRE_REMEDIATION_4.9.0.md) | Snapshot histórico de identidad; no prueba publicación ni validación. |
| 4.8.4 | [Scripts de publicación retirados](../../../releases/archive/v4.8.4/README.md) | Scripts administrativos conservados como evidencia; no ejecutar sobre releases actuales. |

Para instalar la versión vigente, consultar el [README del repositorio](../../../README.md)
y la documentación enlazada desde [`DOCUMENTATION.md`](../../../DOCUMENTATION.md).

Los paquetes locales de versiones anteriores están separados en
[`releases/archive/`](../../../releases/archive/README.md).
