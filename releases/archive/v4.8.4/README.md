# Scripts de publicación retirados de BAGO 4.8.4

Estos scripts son evidencia histórica de la publicación `v4.8.4`:

- `update-release-v4.8.4.ps1` (PowerShell)
- `update-release-v4.8.4.sh` (Bash)

Ambos pueden borrar y volver a subir assets de la release `v4.8.4` en GitHub.
No son herramientas genéricas ni deben ejecutarse para publicar una versión
actual. Se conservan aquí para auditoría; el inventario de efectos los sigue
clasificando como operaciones administrativas de release.
