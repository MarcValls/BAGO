# Local archived release payloads

These are local, versioned release artifacts retained separately from the
current release entrypoints. Their presence preserves bytes; it does not prove
publication, signature trust, installability, or `VALIDATED` status. Resolve
the current product version only from [`../../release_version.txt`](../../release_version.txt).

documentation is indexed separately under `docs/archive/releases/`.
