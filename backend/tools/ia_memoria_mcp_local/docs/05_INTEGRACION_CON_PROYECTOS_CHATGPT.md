# Integración con Proyectos de ChatGPT

Cada proyecto debe cargar identidad, estado vigente, canon, decisiones y enlaces relevantes.

Un enlace interproyecto declara origen, destino, concepto, autoridad, condiciones, fuente y estado. No importa todo el proyecto de origen.

Los proyectos son áreas activas. La memoria MCP es continuidad externa y fuente explícita.
