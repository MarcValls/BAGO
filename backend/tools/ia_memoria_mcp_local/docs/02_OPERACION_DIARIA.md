# Operación diaria

## Apertura

1. `get_context`.
2. Revisar estado, memorias, conflictos y enlaces.
3. Abrir documentos concretos.
4. Realizar la tarea.

## Cierre

Registrar solo decisiones, cambios de estado, productos, fallos, reglas preventivas, verificaciones y siguientes acciones.

## Conflictos

No elegir silenciosamente. Identificar fuente, autoridad y fecha; decidir; confirmar la nueva memoria y deprecar la sustituida.

## Reindexación

Ejecutar `scripts\reindex.cmd` después de editar Markdown manualmente.
