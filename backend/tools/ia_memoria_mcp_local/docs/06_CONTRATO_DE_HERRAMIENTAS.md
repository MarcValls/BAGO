# Contrato de herramientas

## Lectura

`readOnlyHint=true`, `destructiveHint=false`, `idempotentHint=true`, `openWorldHint=false`.

## Escritura aditiva

Propuestas, eventos, proyectos y enlaces añaden información, sin abrir el mundo externo.

## Cambio de estado

Deprecar modifica vigencia y conserva historia.

Configura el cliente con `default_tools_approval_mode = "writes"`.
