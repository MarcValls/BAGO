# Arquitectura general

La memoria externa conserva conocimiento estable, estados, decisiones, relaciones y evidencias con trazabilidad.

## Capas

### Personalización

Define comprensión, veracidad operativa, auditoría y cierre.

### Proyectos de ChatGPT

Agrupan conversaciones y archivos de trabajo. No sustituyen una fuente exacta y versionable.

### Memoria MCP local

Conserva identidad, estado, decisiones, enlaces, propuestas, conflictos y eventos.

## Principio

La memoria automática produce asociaciones. Los documentos producen autoridad.

Markdown es la representación humana. SQLite acelera búsqueda y conserva registros estructurados.
