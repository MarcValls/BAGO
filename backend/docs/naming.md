# Naming convention

New canonical docs in this tree use lowercase `kebab-case` filenames in English.

The existing uppercase core documents (`ARCHITECTURE.md`, `CLAIMS.md`,
`COMMANDS.md`, `LAYERS.md`, `MODULES.md`, `MVP.md`, `SECURITY.md`,
`TESTING.md`, and `TRACEABILITY.md`) remain canonical at their current paths
until a governed repository-wide rename updates all references and external
consumers. Link to their current case; do not create case-only duplicates.

If a doc is renamed, update its canonical filename, all repository references,
`docs/README.md`, and relevant tests in the same change.
