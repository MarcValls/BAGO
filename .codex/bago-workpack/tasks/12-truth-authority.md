# Estado, evidencia y verdad operacional

Usa `bago_truth_auditor`.

Audita la separación entre canon, configuración, proyecto, workspace, sesión, runtime, ejecución, claim,
evidencia y conclusión.

Busca estados falsamente autoritativos: connected, authenticated, verified, completed, saved, running,
success, installed y available.

Cruza este análisis con los conflictos de autoridad encontrados en frontend, backend y workspace.
Entrega un mapa de FUENTE DE VERDAD -> EVIDENCIA -> CONSUMIDORES -> RIESGO.
