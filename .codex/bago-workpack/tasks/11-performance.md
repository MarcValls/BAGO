# Performance

Usa `bago_performance_auditor`.

Audita renders, effects, peticiones, polling, listas, árboles, editor, archivos grandes, parsing, JSON,
búsquedas, procesos, memoria, listeners, timers, cleanup y caches.

No optimices. Clasifica cada hallazgo como MEDIDO, EVIDENTE_POR_CODIGO o HIPOTESIS.
Prioriza problemas capaces de afectar experiencia, estabilidad o escalabilidad.
