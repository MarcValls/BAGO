Flujo de instalación correcto

1. Descargá el BAGO Manager Installer (.exe) desde el botón principal o GitHub Releases.

2. El ZIP es solo para desarrollo o inspección manual; no es el camino por defecto.

3. Ejecutá el instalador o, si vas a desarrollar, descomprimí el ZIP donde prefieras.

4. Abrí el BAGO Manager para gestionar tus instalaciones, roles y sesiones.

¿Preferís verificar antes? Los hashes SHA-256 y el código fuente están en GitHub Releases.
