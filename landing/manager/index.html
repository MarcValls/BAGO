BAGO · Gestor de Instalaciones

standalone · offline · v4.5.0

Gestiona todas tus instalaciones BAGO

Controla instalaciones, roles active/des/ign, piezas, compatibilidad y evidencia. Las descargas de GitHub son solo una accion mas del gestor, no el centro de la app.

Cómo usarlo como gestor

  1. Revisa primero Node Control: registry, piezas, matriz y conectores.
  2. Comprueba roles active/des/ign y las instalaciones detectadas.
  3. Usa releases solo para instalar, actualizar o probar una version aparte.
  4. En Electron, ejecutar abre PowerShell visible; en navegador, se copian comandos.
Aviso de ejecución: los botones ejecutar abren una ventana PowerShell visible con el comando. No se ejecuta nada oculto ni silencioso en segundo plano. En la versión web solo se copian comandos.
