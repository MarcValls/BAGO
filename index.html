Session-First AI Control Plane

BAGO es una CLI local-first que orquesta proveedores de IA, mantiene el contexto entre cambios de modelo, y aprende de tu estilo de conversación para no ser invasivo.

Instalar ahora Ver en GitHub

¿Por qué BAGO?

Sesiones persistentes

Las conversaciones sobreviven a cambios de proveedor y modelo sin perder contexto.

Motor de intenciones

Clasifica automáticamente si hablas, pides revisar, ejecutar o trabajar en código, y solo ofrece herramientas cuando corresponde.

Multi-provider

Soporta Ollama local, Copilot, Anthropic, OpenRouter y Codex desde una misma interfaz.

Auto-entrenamiento

Reescanea tu historial antes de cada compresión de contexto para aprender cómo hablas y refinar su clasificador.

Instalación rápida

PowerShell 
git clone https://github.com/MarcValls/BAGO.git
cd BAGO
.\install-v4.ps1
python bago_core\cli.py llm start --provider ollama-local --model llama3.2:3b
