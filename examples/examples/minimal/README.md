# Minimal BAGO example

This is a minimal example project using **BAGO core**.

## Purpose

- show the smallest reproducible setup,
- keep runtime state local,
- run the standard cycle:
  - `bago validate`
  - `bago status`
  - `bago next`
  - implement change
  - `bago done`
  - `bago audit full`

## Included

- `.bago/state.example/` template state for bootstrapping

## Notes

This folder is intentionally generic and avoids project-specific content.
