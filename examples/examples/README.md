# Examples BAGO

Esta capa contiene proyectos y herramientas reproducibles extraídos del ZIP original para que no contaminen el core.

Incluye, si estaban presentes en la fuente:

- `tragaperras_bot/`: proyecto real con motor, UI, assets y exports de base de datos.
- `web_tools/`: herramientas HTML/JS generadas.
- `ableton-template/`: artefacto demostrativo musical.
- `bago_internal/`: ejemplos internos de prompts/sesiones.

Regla: un ejemplo puede tener assets y evidencia propia, pero no debe ser dependencia obligatoria del core.
